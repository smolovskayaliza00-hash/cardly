# Просмотр на iPhone внутри Telegram

Telegram открывает Mini App только по **HTTPS**. Самый надёжный путь для прототипа —
бесплатный GitHub Pages с постоянной ссылкой. Ссылку указываем в @BotFather один раз.

## Шаг 1. Опубликовать приложение на GitHub Pages

1. Создайте на GitHub пустой репозиторий, например `cardapp` (можно приватный при платном
   тарифе GitHub; на бесплатном Pages работает только для публичных репозиториев).
2. Отправьте код:
   ```bash
   cd cardapp
   git remote add origin https://github.com/<ваш-логин>/cardapp.git
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Откройте вкладку **Actions**. Workflow «Deploy Mini App to GitHub Pages» соберёт и
   опубликует приложение за 1–2 минуты.
5. Адрес будет вида `https://<ваш-логин>.github.io/cardapp/`. Проверьте его в Safari.

> Приложение собирается в mock-режиме: всё работает в браузере, сервер не нужен.

## Шаг 2. Создать бота в @BotFather

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Введите отображаемое имя (например, `Aurum Cards Demo`) и username, оканчивающийся
   на `bot` (например, `aurum_cards_demo_bot`).
3. BotFather пришлёт **токен**. Сохраните его в надёжном месте. Для прототипа он не нужен,
   понадобится бэкенду на этапе 2. Никому не отправляйте и не коммитьте его.

## Шаг 3. Привязать Mini App к боту

**Кнопка меню (самое простое):**

1. В @BotFather: `/mybots` → ваш бот → **Bot Settings** → **Menu Button** →
   **Configure menu button**.
2. Отправьте URL: `https://<ваш-логин>.github.io/cardapp/`
3. Отправьте название кнопки: `Открыть`.

**Дополнительно — прямая ссылка t.me/…:**

1. `/newapp` → выберите бота → название, описание, картинка 640×360 (можно любую).
2. Укажите тот же URL и короткое имя (например, `app`).
3. Ссылка вида `https://t.me/aurum_cards_demo_bot/app` открывает приложение сразу.

**Включить полноэкранный режим (необязательно):** `/mybots` → бот → Bot Settings →
Configure Mini App → Enable/Full-screen.

## Шаг 4. Открыть на iPhone

1. Найдите бота в Telegram на iPhone → `/start` (или «Запустить»).
2. Нажмите кнопку **«Открыть»** слева от поля ввода.
3. Приложение откроется с нативной кнопкой «Назад» в шапке и главной кнопкой внизу.

## Обновления

Каждый `git push` в `main` автоматически пересобирает сайт. В Telegram достаточно закрыть и
снова открыть Mini App. Если видна старая версия, потяните вниз, чтобы закрыть, и откройте заново.

## Альтернатива: временный туннель для разработки

Если нужно смотреть изменения без пуша:

```bash
pnpm dev                                         # терминал 1
cloudflared tunnel --url http://localhost:5173   # терминал 2 (установить: brew install cloudflared)
```

cloudflared выдаст адрес `https://<случайное>.trycloudflare.com`. Его можно временно указать
в Menu Button бота. Адрес меняется при каждом запуске, поэтому для постоянного просмотра
лучше GitHub Pages.

## Частые проблемы

| Симптом | Решение |
|---|---|
| Белый экран | проверьте, что URL заканчивается на `/` и открывается в Safari |
| «Blocked request. This host is not allowed» | в `vite.config.ts` уже стоит `allowedHosts: true`; перезапустите `pnpm dev` |
| Кнопка меню не появилась | перезапустите Telegram, проверьте Menu Button в @BotFather |
| Хочу начать сначала | Профиль → «Начать как новый пользователь» или «Показать онбординг» |
