## 2026-10-14 — Этап 1: прототип готов

**Сделано**
- Создана отдельная папка `cardapp/`. Рабочая директория была пустой, другие проекты не затронуты.
- С согласия установлены Node.js 20.20.2 (контрольная сумма проверена) и pnpm 9.15.9.
- Монорепозиторий: `apps/miniapp`, `apps/api`, `packages/shared`.
- Mini App, 11 экранов на демо-данных: онбординг, главная, карты, карта, выпуск, пополнение,
  статус пополнения, история, тарифы, профиль, верификация.
- Интеграция с Telegram: MainButton, BackButton, haptics, цвета шапки, тема, данные пользователя.
- Бэкенд-каркас: проверка подписи initData, REST API, адаптеры `CardProvider` / `PaymentProvider`
  (mock и шаблон партнёра), обработка вебхуков, черновик схемы PostgreSQL.
- Документация: архитектура, локальный запуск, iPhone/BotFather, интеграция с партнёром, комплаенс.
- Автодеплой на GitHub Pages (`.github/workflows/deploy-pages.yml`).

**Проверено**
- `pnpm typecheck`, `pnpm build` — без ошибок.
- `pnpm test` — 6/6 (подпись initData, авторизация, изоляция пользователей, пополнение).
- Живой прогон API: пополнение 10 000 ₽ → +$102,72 (комиссия 2%, курс 95,40),
  лимит 5 карт по тарифу «Премиум» срабатывает.
- Найден и исправлен баг: демо-карты разных пользователей на сервере имели одинаковые id.

**Не проверено**
- Внешний вид интерфейса в браузере (в окружении нет браузера).

## 2026-10-14 — Решения по плану

- **Стек:** React 18 + TypeScript + Vite 6 + Tailwind 4 + Framer Motion + TanStack Query + Zustand;
  бэкенд Node + Fastify 5 + Zod.
- **Telegram SDK:** официальный `telegram-web-app.js` с собственной типизированной обёрткой вместо
  `@telegram-apps/sdk-react` (меньше зависимостей, стабильнее между версиями).
- **Дизайн:** графит + золото, тёмная тема по умолчанию, есть светлая и «как в Telegram».
- **Просмотр на iPhone:** бот через @BotFather + GitHub Pages как постоянный HTTPS-адрес.
- **Ограничения этапа:** без реальных платежей, без выпуска карт, без запроса платёжных данных.
- **Комплаенс:** зафиксированы санкционные и регуляторные риски ([compliance.md](compliance.md)).
  До приёма реальных денег нужна консультация юриста.
