## 2026-10-14 — Решения по плану

- **Стек:** React 18 + TypeScript + Vite 6 + Tailwind 4 + Framer Motion + TanStack Query + Zustand;
  бэкенд Node + Fastify 5 + Zod.
- **Telegram SDK:** официальный `telegram-web-app.js` с собственной типизированной обёрткой вместо
  `@telegram-apps/sdk-react` (меньше зависимостей, стабильнее между версиями).
- **Дизайн:** графит + золото, тёмная тема по умолчанию, есть светлая и «как в Telegram».
- **Просмотр на iPhone:** бот через @BotFather + GitHub Pages как постоянный HTTPS-адрес.
- **Ограничения этапа:** без реальных платежей, без выпуска карт, без запроса платёжных данных.
- **Комплаенс:** зафиксированы санкционные и регуляторные риски ([compliance.md](compliance.md)).
  До приёма реальных денег нужна консультация юриста.
